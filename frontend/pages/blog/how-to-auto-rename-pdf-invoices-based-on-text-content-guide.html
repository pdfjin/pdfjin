How to auto-rename PDF invoices based on text content

Automating PDF Invoice Renaming Based on Text Content

Automatically renaming PDF invoices streamlines document management by using their internal text content to create descriptive filenames. The core process involves three critical steps: extracting all readable text from the PDF, parsing this text to identify key data points like invoice numbers, dates, and vendor names, and finally, using this extracted information to construct a new, standardized filename for the document.

Understanding the Renaming Workflow

The journey from a generic PDF filename to a structured one requires a systematic approach. This workflow addresses both digitally native PDFs and scanned image-based invoices.

  • Text Extraction Obtain the full text content of the PDF. If the PDF is a scanned image, Optical Character Recognition (OCR) is essential to convert the image into searchable text.
  • Data Parsing Once text is available, leverage regular expressions (regex) or more advanced pattern matching to locate and isolate specific data fields, such as "Invoice #", "Date", "Total Amount", or "Vendor Name".
  • Filename Construction and Rename Combine the extracted data points into a consistent filename format (e.g., "VENDOR_INV[InvoiceNumber]_DATE.pdf") and then programmatically rename the file.

Prerequisites and Setup for Automation

To implement an automated renaming solution, Python is an excellent choice due to its robust libraries for PDF processing and text manipulation. You will need a Python environment and specific libraries.

Required Tools and Libraries

  • Python 3.x Your primary scripting language.
  • pypdf or pdfminer.six For extracting text from digitally native PDFs.
  • Pillow (PIL Fork) For image processing, particularly if using OCR.
  • pytesseract A Python wrapper for Google's Tesseract OCR engine.
  • Tesseract OCR Engine The underlying OCR application. Install this separately for your operating system.

You can install most Python libraries via pip:

pip install pypdf pillow pytesseract

For scanned documents, ensure Tesseract is correctly installed and accessible in your system's PATH. If your PDFs are scans, converting them to searchable PDFs first is crucial. For this, you might use an online OCR PDF tool to make the content extractable.

2 Defining Data Extraction Patterns

Once you have the text, regular expressions are your best friend for pulling out specific data points. The effectiveness of your regex patterns depends heavily on the consistency of your invoice layouts.

Common Data Points and Regex Patterns

Data Point Example Text Example Regex Pattern
Invoice Number Invoice # INV-2023-001 r"(?:Invoice|Inv)\s*[#No.]*\s*([A-Za-z0-9\-]+)"
Date Date: 12/01/2023 r"(?:Date|Bill Date):\s*(\d{1,2}[/\-]\d{1,2}[/\-]\d{2,4})"
Vendor Name FROM: ACME Corp. r"(?:FROM|Vendor):\s*([A-Za-z\s.,&-]+)"
Total Amount TOTAL DUE: $1,234.56 r"(?:TOTAL|Total Due):\s*[$€£]?\s*([\d,]+\.\d{2})"

Define a function to apply these patterns and extract the values:


import re

def extract_invoice_data(text):
    data = {
        "invoice_num": "UNKNOWN",
        "date": "NODATE",
        "vendor": "NOVENDOR"
    }

    # Example patterns - adapt to your specific invoice formats
    patterns = {
        "invoice_num": r"(?:Invoice|Inv)\s*[#No.]*\s*([A-Za-z0-9\-]+)",
        "date": r"(?:Date|Bill Date)[:\s]*(\d{1,2}[/\-]\d{1,2}[/\-]\d{2,4})",
        "vendor": r"(?:FROM|Vendor):\s*([A-Za-z\s.,&-]+)"
    }

    for key, pattern in patterns.items():
        match = re.search(pattern, text, re.IGNORECASE)
        if match:
            # Clean up extracted vendor name if necessary (e.g., remove newlines)
            if key == "vendor":
                data[key] = match.group(1).strip().replace('\n', ' ')
            else:
                data[key] = match.group(1).strip()
    return data

3 Constructing the New Filename

Standardize your filenames. A common format includes the vendor, invoice number, and date.

Function to Construct Filename


def construct_new_filename(invoice_data):
    invoice_num = invoice_data.get("invoice_num", "UNKNOWN").replace('/', '-')
    date = invoice_data.get("date", "NODATE").replace('/', '-')
    vendor = invoice_data.get("vendor", "NOVENDOR").replace('/', '_').replace('.', '')

    # Example format: VENDOR_INV[InvoiceNumber]_DATE.pdf
    new_name = f"{vendor.upper()}_INV{invoice_num}_{date}.pdf"
    return new_name

Ensure the filename is sanitized to remove characters that are invalid in file paths (e.g., '/', ':', '?').

4 Executing the Rename

The final step is to use Python's os module to rename the file.

Function to Rename File


import os

def rename_pdf_file(original_path, new_filename, output_dir="renamed_invoices"):
    if not os.path.exists(output_dir):
        os.makedirs(output_dir)
    
    original_dirname, original_basename = os.path.split(original_path)
    new_path = os.path.join(output_dir, new_filename)

    try:
        os.rename(original_path, new_path)
        print(f"Renamed '{original_basename}' to '{new_filename}' in '{output_dir}'")
        return True
    except OSError as e:
        print(f"Error renaming file {original_path} to {new_path}: {e}")
        return False

Consider moving the renamed files to a separate directory to keep your source folder clean.

Robustness and Error Handling

Real-world invoices are rarely perfectly uniform. Your script should account for:

  • Missing Data What if an invoice number or date is not found? Use default placeholders.
  • Multiple Formats Design flexible regex patterns or create a dictionary of patterns to try against different known invoice layouts.
  • OCR Accuracy OCR is not always 100% accurate. Implement confidence checks if possible or manual review for low-confidence extractions.
  • File Permissions Ensure your script has the necessary permissions to read and rename files.
